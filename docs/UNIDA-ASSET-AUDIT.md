## 一、审计方法

1. 用 PIL 读取每个文件的真实尺寸、色彩模式、是否含 alpha 通道、全透明像素占比
2. 逐张打开目视核验内容（是"完整设计展板"还是"可独立取用的素材"）
3. 对含 alpha 的文件，做连通域分析，判断内部元素是否真能单独切出
4. 对切出的元素做边缘检查（AI 出图普遍带洋红/蓝紫彩色描边光晕）

## 三、两个重要发现

### 1. 「三人可抠图」其实不可抠

文件名有误导性。它有 alpha 通道，但**全图 0 个全透明像素**——背景是烘焙进图里的浅紫白雾面渐变。人物发丝、球拍网线、吉他弦这些细结构已经和背景混在一起，用任何抠图算法都会断线。

**处置**：不抠。当整幅插画使用，放在浅紫底页面里，边缘用径向淡出遮罩融进背景即可。

### 2. 设计系统板的文字是假的

`UNIDA有你搭紫色UI设计系统海报.png` 上的色值、说明文字全是 AI 生成的伪文字（放大后是"主蕖""窖籑笱F"这类乱码）。**不能用 OCR 读色值**。

**处置**：改为直接采样色块像素中心点，得到真实色值：

| 采样位置 | 采样值 | 板面标注意图 |
|---|---|---|
| 第 1 块（主紫） | `#8056FC` | 主紫 |
| 第 2 块（浅紫） | `#A685FC` | 浅紫 |
| 第 3 块（冰紫） | `#E8DAFE` | 极浅紫 |
| 第 4 块（暖黄） | `#FED146` | 活力黄 |
| 第 5 块（蜜橙） | `#FEAB89` | 辅助橙 |
| 第 6 块（薄荷） | `#93EDCF` | 辅助绿 |

另：`有你搭字.png` 里「有你搭」三个字的实色文字采样为 `#39007E`，这是字标专用墨紫，比 UI 里的深紫更深。

## 五、包体积：一个必须先解决的硬问题

| 目录 | 体积 | 说明 |
|---|---|---|
| 审计前 `static/` | **32.91 MB** | 含 8 张废弃的 AI 生成图（`Premium_3D_crystal_glass_illus_*.png`、`CRITICAL__NO_watermark_*.png` 等），单张 1.8~2.8 MB |
| 其中 `login-design-fill.png` | 2.66 MB | 登录页正在使用的整图，单张就超过主包上限 |
| 新增 `static/unida/` | 1.23 MB | 本次清洗后的发布版素材 |

微信小程序主包上限 **2 MB**。当前 `static/` 有 32.91 MB，**真机上传会直接失败**。

### 建议处置（需你确认后执行）

1. **删除 8 张废弃生成图 + `login-bg.png` + `login-hero-final.png`** —— 约 20 MB，都是被用户手绘稿取代的旧迭代产物
2. **`login-design-fill.png` 转 JPEG q88** —— 2.66 MB → 416 KB，画面内容零差别（它本身没有透明通道）
3. **`home-banner.png` 同理转 JPEG** —— 894 KB → 约 180 KB
4. 后续页面按分包组织，把人物立绘/背景放进对应分包

做完 1~3 项，`static/` 可压到 **约 2.0 MB 以内**，具备真机上传条件。
