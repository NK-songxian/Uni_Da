# UNIDA 页面规划 v1.0

> 第一阶段 · 第 3 步产出
> 目标：把 UNIDA 做成「有品牌、有固定视觉语言、有专属 IP、有交互特色」的校园社交产品，而不是紫色主题的通用社区模板

---

## 一、先定一件事：首页到底服务于什么

模板社区的首页是「搜索框 + 8 宫格 + 猜你喜欢卡片流」。UNIDA 不是这个逻辑。

UNIDA 的核心动作只有一个：**在 30 秒内，让一个学生找到"现在就能一起做点什么"的人。**

所以首页的信息优先级是：

```
找人（现在谁缺人） > 找活动（这周有什么） > 看动态（同校发生什么）
```

不是「先逛再看」，而是「先匹配再逛」。这个顺序决定了首页不能做成卡片流瀑布。

---

## 二、首页模块规划

共 8 个模块，**每个模块用不同的卡片形态**，避免"复制粘贴同一张卡"。

### 模块 1 · 顶部身份栏（吸顶）

| 项 | 内容 |
|---|---|
| 左 | 定位图标 + 学校名（如"江南大学"）+ 下拉箭头 → 点击切换学校 |
| 中 | 品牌横版 logo（`brand/logo-horizontal.png`，宽 200rpx） |
| 右 | 消息铃铛 + 未读角标（红点，最多显示 "9+"） |
| 背景 | 透明，滚动后渐变为白色 + 细分割线 |

**为什么不用整行搜索框**：模板才把搜索框焊在顶部。UNIDA 的搜索是低频动作，收进 hero 里做成一个小胶囊即可。

### 模块 2 · Hero 主视觉

| 项 | 内容 |
|---|---|
| 插画 | `characters/trio-back.png`（三人背影），贴底对齐，底部用径向遮罩融进底色 |
| 背景 | `backgrounds/bg-campus-sky.jpg` 叠在插画后，形成天空纵深 |
| 文案 | 主标「在校园，找到和你同频的人」；副标「今天已有 <mark>1,284</mark> 位同学找到搭子」 |
| 交互 | 搜索胶囊（半透明白，宽 60%，点击进搜索页） |
| 动效 | 入场时三人从下方 24rpx 上移淡入；数字逐位滚动 |

**为什么必须有真实数字**：模板写"欢迎来到本平台"，产品写"今天有 1284 人在这"。后者才是社交产品。

### 模块 3 · 类目入口（3D 图标，横向两行）

6 个入口，用真实 3D 素材，**不用扁平色块**：

| 入口 | 素材 | 落到 |
|---|---|---|
| 学习组队 | `icon-study.png` | 找搭子·学习 |
| 运动搭子 | `icon-run.png` | 找搭子·运动 |
| 校园活动 | `icon-horn.png` | 活动列表 |
| 生活互助 | `icon-gift.png` | 互助（取快递/代买/借东西） |
| 社团招新 | `icon-team.png` | 社团 |
| 同校广场 | `icon-planet.png` | 动态广场 |

布局：2 行 × 3 列，卡片型 = **A 玻璃信息卡**（面板统一包一层玻璃底），单个入口无边框。

**为什么不做八宫格**：八宫格是电商分类的视觉语言，社交产品用会显得像商城。

### 模块 4 · 「现在可以搭」即时组局（核心差异化）

| 项 | 内容 |
|---|---|
| 标题 | 「现在可以搭」+ 副标「2 小时内 · 同校 · 还缺人」+ 右侧「全部」 |
| 形态 | 横向滑动卡片流，卡片宽 560rpx |
| 卡片型 | **B 插画出血卡**：活动插画顶到卡片上沿，圆角只在上方，下方白色区域承载信息 |
| 卡内信息 | 活动名 / 时间（还有 40 分钟开始）/ 地点（南区体育馆）/ 人数进度条 3/4 / 头像堆叠 / 「加入」按钮 |
| 空态 | 无数据时显示 U 星球 + "这个时段还没人组局，你来发第一个？" |

**为什么这是首页最重要的模块**：它对应"现在就能一起做点什么"，是 UNIDA 和豆瓣小组/校园墙的根本区别。

### 模块 5 · 同校动态（feed）

| 项 | 内容 |
|---|---|
| 标题 | 「同校动态」+ tab 切换（全部 / 找搭子 / 求助 / 出闲置） |
| 形态 | 纵向卡片流 |
| 卡片型 | **A 玻璃卡**，但每张卡左侧有 4rpx 彩色竖条（按分类变色：紫/绿/黄/蓝） |
| 卡内 | 头像 + 昵称 + 学院年级 + 时间；正文 3 行截断；图片九宫格（1/2/3/4/9 五种排版）；底部 点赞 / 评论 / 「我也要搭」 |
| 差异化 | 正文里出现兴趣关键词自动高亮为 chip（如 `#羽毛球`），点击进话题 |

### 模块 6 · 校园活动（横滑大卡）

| 项 | 内容 |
|---|---|
| 形态 | 横滑，卡片 620×420rpx，插画铺满 + 底部渐变遮罩 + 白字 |
| 数据 | 活动名 / 主办方 / 时间 / 地点 / 已报名 128 人 |
| 角标 | 左上角「即将开始」黄色角标 / 「报名中」绿色角标 |

### 模块 7 · 同频推荐（头像墙）

| 项 | 内容 |
|---|---|
| 逻辑 | 按兴趣标签重合度排序，展示 6~8 人 |
| 形态 | 2 行横滑小卡：圆形头像 + 昵称 + 2 个共同兴趣 chip + 「打招呼」 |
| 卡片型 | **C 标签流卡**（无边框，靠 chip 撑结构） |
| 为什么 | 这是"找到同频的人" slogan 的直接兑现，必须出现在首页 |

### 模块 8 · 结尾互动

U 星球（`mascot/u-planet.png`）+ 一句「UNIDA 想认识你，填完兴趣会推荐得更准」+ 「完善兴趣」按钮。

页面底部留白 `calc(200rpx + env(safe-area-inset-bottom))`。

### 首页三态（模板通常只做正常态）

| 状态 | 表现 |
|---|---|
| 骨架屏 | 灰块 + 呼吸动画，形状与真实模块一致（不能是转圈） |
| 新用户空态 | 隐藏模块 5/6/7，把模块 3 放大，模块 4 显示引导卡 |
| 断网 | U 星球 + "网络走丢了" + 重试按钮 |

## 三、其余四个核心页

### 发现页（找搭子主战场）

结构：顶部 tab（搭子 / 活动 / 社团）→ 筛选条（时间 / 地点 / 类型 / 人数）→ 瀑布流双列卡片。

关键差异：**筛选条用胶囊 chip，不用下拉菜单**；卡片右下角有「还缺 1 人」的实时人数环。
素材：`char-girl-cap`、`char-boy` 用作无结果时的插画。

### 发布页

结构：发布类型四选一（找搭子 / 发活动 / 求助 / 出闲置）→ 表单 → 预览卡。
关键差异：**发布页顶部是四个彩色大按钮，不是 tab**；选中后整个页面主色跟着变。
素材：`mascot/u-planet` 做成功反馈（发布成功 = U 星球跳出 + 一句话）。

### 消息页

结构：顶部三个入口（互动通知 / 搭子申请 / 系统消息）→ 会话列表。
关键差异：会话列表左侧不是方头像，是**圆形头像 + 右下角小状态点**（在线绿点 / 正在组局紫点）。
素材：`deco-chat`、`deco-appicon`。

### 我的页（已有权威稿：`个人中心.png`）

严格按用户手绘稿实现，结构：
品牌栏 + 铃铛 → 樱花校园 hero（含头像/昵称/认证/学院/签名/编辑资料）→ 4 数据块（**D 数据块型**，无框）→ 我的校园生活 5 图标 → 我的小组件 2×2（本周目标环 / 连续签到 / 活动日历 / 成长勋章 Lv.）→ 列表组 → 底部 tabbar。

素材：`bg-campus-building`、`characters/trio-back`、`deco-shield`（认证角标）。

## 五、开发顺序（一次只做一个，做完验收再下一个）

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| 1 | **首页** | 8 模块全部实现；三态齐全；与 `个人中心.png` 同一套质感；真机截图无遮挡 |
| 2 | 发现页 | 双列瀑布 + 筛选 chip 交互正常 |
| 3 | 活动详情 / 组局详情 | 报名流程可走通 |
| 4 | 我的页 | 与手绘稿 1:1 |
| 5 | 消息页 | 会话列表 + 通知分类 |
| 6 | 发布页 | 四类发布表单 |
| 7 | 其余 22 页 | 按同规范批量 |

**不做**：一次性改完 29 页。没达标的页面照抄一遍等于把丑复制 29 次。

## 六、首页验收清单

- [ ] 遮住 logo，只看配色和卡片，能认出是 UNIDA

- [ ] 零 emoji
- [ ] 零"纯白卡片 + 灰阴影"的模板卡
- [ ] 底部内容不被 tabbar 遮挡
