# UNIDA（有你搭）· UI 设计规范 V1.0「动感青春」

> 依据：`UNIDA开发定位V1.md` 第四章品牌视觉要求 + `UI设计参考/` 5 张既定效果图。
> 本规范是"动感青春"风格的唯一事实来源，所有页面/组件按此实现，延续既有品牌，不重新设计。

## 1. 设计定位

年轻、时尚、动感、活力、阳光、社交、校园、潮流。不做企业管理系统、不做老式论坛、不过于幼稚。
参考现代年轻化社交产品 + 生活方式社区：精致圆角卡片、层次阴影、轻量渐变、趣味图标、真实校园摄影感。

## 2. 色彩系统（来自定位文档，与原图一致）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `$unida-primary` | `#7B61FF` | 主色：主按钮、强调、Tab 激活 |
| `$unida-primary-light` | `#B59BFF` | 辅助紫：渐变副色、浅强调 |
| `$unida-bg` | `#F7F2FF` | 页面背景（浅紫雾）|
| `$unida-card` | `#FFFFFF` | 卡片底色 |
| `$unida-green` | `#34D399` | 活力绿：成功、在线、运动分类 |
| `$unida-orange` | `#FF8A3D` | 强调橙：热度、提醒 |
| `$unida-yellow` | `#FFD76A` | 阳光黄：积分、高亮 |
| `$unida-text` | `#29243D` | 文字主色 |
| `$unida-text-sub` | `#8B85A5` | 次级文字 |
| `$unida-divider` | `#EFEAF8` | 分割线 |

**渐变规范（轻量，不滥用）：**
- 品牌主渐变：`linear-gradient(135deg, #7B61FF 0%, #B59BFF 100%)` —— 用于 Banner、主按钮、发布键。
- 暖色渐变：`linear-gradient(135deg, #FF8A3D 0%, #FFD76A 100%)` —— 用于活动/积分强调。
- 背景一律纯色 `#F7F2FF`，不用大面积渐变。

## 3. 字体与字号（rpx，750 设计稿）

| 层级 | 字号 | 字重 | 场景 |
|---|---|---|---|
| Slogan/大标题 | 44–56 | 700 | 登录页 Slogan、Banner 主标 |
| 模块标题 | 32–34 | 700 | 分区标题 |
| 卡片标题 | 28–30 | 600 | 活动/卡片标题 |
| 正文 | 26–28 | 400 | 描述信息 |
| 辅助/说明 | 22–24 | 400 | 时间、地点、标签 |
| Tab 文字 | 20–22 | 500 | 底部导航 |

字族：系统默认无衬线（`PingFang SC` / 系统字体），数字可加粗突出。

## 4. 圆角 / 阴影 / 间距

- 圆角：卡片 `24rpx`，按钮 `999rpx`（胶囊），标签 `12rpx`，头像 `50%`，图片 `16rpx`。
- 阴影：`0 8rpx 24rpx rgba(123, 97, 255, 0.10)`（卡片轻投影）；发布键 `0 12rpx 28rpx rgba(123, 97, 255, 0.35)`。
- 间距栅格：8 / 16 / 24 / 32 rpx。页面左右边距 `24rpx`，卡片间距 `20rpx`。

## 5. 图标与视觉

- 分类图标：用 emoji 作趣味图标（📚🏃🎮📖🛵🎪），外衬彩色渐变圆角底（96rpx）。后续可换 iconfont/SVG。
- 品牌插画：登录页用 CSS 渐变 + 几何造型还原"动感青年"氛围；真实人物插画建议 AI 生成后替换（消耗积分，需确认）。
- 图片：活动封面用 `aspectFill` + `lazy-load`；上线前压缩为 WebP 并走 CDN。

## 6. 动效（克制、流畅）

- 页面/卡片入场：`fade + translateY(16rpx)`，200–300ms。
- 按钮点击：`transform: scale(0.96)` 反馈。
- 发布键：轻微呼吸动画（`scale 1↔1.04`），有活力但不刺眼。
- 遵循系统 `prefers-reduced-motion`（如平台支持）。

## 7. 组件规范

| 组件 | 关键接口 | 说明 |
|---|---|---|
| unida-tabbar | `current`（当前 tab 索引）| 5 栏，中间凸起发布键；用 `@navigate` 事件或组件内 reLaunch |
| unida-card | `item`（活动数据对象）| 封面+标题+标签+时间地点+人数+价格，整卡可点 |
| unida-category | `list`（分类数组）、`@tap` | 横向图标入口，彩色渐变底 |
| unida-search | `placeholder`、`@focus` | 胶囊搜索框 |

所有可点击控件必须有真实交互；表单必须有校验/错误提示/提交态（后续阶段实现）。

## 8. 页面框架

底部 5 入口：首页 / 发现 / **发布（中间凸起）** / 消息 / 我的。社区整合进发现，消息页承载私聊与通知。
C 端与 admin 后台并存：C 端为 `pages/login|home|discover|publish|message|mine`，admin 模板页面保留。

## 9. 合规前置（提审必查，以微信官方最新规范为准）

- 社交+用户发布内容：需接入内容安全检测（msgSecCheck），建立举报机制。
- 手机号/位置/身份：需配置用户隐私保护指引 + 隐私弹窗授权后再调用接口。
- 微信登录 code 必须发服务端换 session_key，前端只存自定义登录态 token（禁止前端存 session_key）。
- 校园身份认证涉及个人信息，最小必要收集。

## 10. 交付节奏

- 本阶段（阶段 3/6）：设计规范 + 设计令牌 + 6 个核心页面 UI（可运行、本地 mock 数据）。
- 后续阶段：业务子页 → 云函数/数据库 → 联调 → 测试 → 提审。
