## 2. 字体

展板规范：**标题 思源黑体 / 阿里巴巴普惠体 B，正文 思源黑体 / 阿里巴巴普惠体 R，数字 DIN / Poppins。**

### 2.1 小程序落地策略

微信小程序不能可靠加载外链字体（体积 + 首屏白字问题），所以：

- **中文**：用系统字体。iOS 落到 PingFang SC，Android 落到系统默认。**靠字重和字号拉开层次，不靠字体族。**
- **数字/英文**：用 `font-family: 'DIN Alternate', 'Poppins', -apple-system, sans-serif` 优先命中 iOS 的 DIN Alternate，Android 自然回退，不影响可读性。
- **品牌字标**（"UNIDA""有你搭"）**一律用图片**，不用字体排版 —— 现有 `brand/logo-horizontal.png` 已是矢量级清晰度。

### 2.2 字阶

| 层级 | 字号 | 字重 | 场景 |
|---|---|---|---|
| Display | 56rpx | 700 | 页面主标题（"发现"、"我的"） |
| H1 | 44rpx | 700 | 区块大标题 |
| H2 | 36rpx | 600 | 卡片标题、活动名 |
| H3 | 32rpx | 600 | 列表标题 |
| Body | 28rpx | 400 | 正文、描述 |
| Caption | 24rpx | 400 | 时间、地点、计数 |
| Micro | 22rpx | 500 | 角标、标签内文字 |

### 2.3 字距与行高

- 大标题 `letter-spacing: -0.5rpx`（收紧，显得笃定）
- 正文 `line-height: 1.6`
- 数字强调 `letter-spacing: 0`

## 3. 形状与质感

### 3.1 圆角

| Token | 值 | 用在哪 |
|---|---|---|
| `radius-xs` | 12rpx | 标签、角标 |
| `radius-sm` | 20rpx | 输入框、小按钮 |
| `radius-md` | 28rpx | 卡片（默认） |
| `radius-lg` | 36rpx | 大面板、弹层 |
| `radius-pill` | 999rpx | 胶囊按钮、筛选 chip |
| `radius-squircle` | 40rpx | 图标容器（展板里的 squircle 感） |

### 3.2 阴影（只有 3 档，不要新造）

```scss
// 1. 卡片浮起（最常用）
box-shadow: 0 8rpx 24rpx rgba(123, 97, 255, 0.08);

// 2. 强调浮起（弹层、发布球）
box-shadow: 0 14rpx 36rpx rgba(123, 97, 255, 0.22);

// 3. 内高光（玻璃质感必需）
box-shadow: inset 0 2rpx 0 rgba(255, 255, 255, 0.95);
```

### 3.3 玻璃层配方（首页已验证）

```scss
background: linear-gradient(150deg, rgba(255,255,255,.94) 0%, rgba(247,242,255,.88) 100%);
border: 2rpx solid rgba(255,255,255,.9);
border-radius: 32rpx;
box-shadow: 0 14rpx 36rpx rgba(123,97,255,.12), inset 0 2rpx 0 rgba(255,255,255,.95);
```

> ⚠️ 登录页控件是**完全透明**的（用户明确要求，不许加毛玻璃）。玻璃层只用于内容卡片，不能用在登录悬浮框上。

### 3.4 间距（8 的倍数）

`8 / 12 / 16 / 24 / 32 / 48 / 64rpx`
页面左右安全边距统一 **32rpx**；卡片内边距 **24~28rpx**；区块间距 **40rpx**。

## 4. 动效

原则：**只有"入场"和"反馈"，没有循环乱动。**

| 场景 | 动效 | 时长/曲线 |
|---|---|---|
| 页面/卡片入场 | 上移 24rpx + 淡入 | 320ms `cubic-bezier(.22,.9,.3,1)`，同组错峰 60ms |
| 按钮按下 | `scale(0.96)` | 120ms ease-out |
| 发布球点击 | 弹出 1 → 1.08 → 1 | 260ms spring |
| 收藏/点赞 | 图标 scale 1 → 1.3 → 1 | 300ms |
| 骨架屏 | 透明度 0.5 → 1 呼吸 | 1.4s 循环（唯一的循环动效） |
| 数字变化 | 逐位滚动 | 400ms |

禁止：3D 翻转、旋转 360°、无限浮动、粒子爆炸 —— 这是"AI 味"的主要来源。

## 5. 图标

### 5.1 双轨制

| 类型 | 形态 | 来源 |
|---|---|---|
| **功能/商业图标** | 线性，2rpx 描边，24×24 网格 | `static/icons/*.png`（自绘 20 个，白色） |
| **内容/类目图标** | 3D 立体，带光影 | `static/unida/illustrations/icon-*.png`（6 个） |

规则：**同一个卡片里不能混用两种。** 功能按钮用线性，内容入口用 3D。

### 5.2 底部导航图标

展板 `元素3.png` 定义的形态：**squircle 容器 + 白色线性图标**，选中态为紫色渐变容器，未选中为透明容器。

现有自绘白色线性图标可复用，但缺"选中态容器"——这个用 CSS 做（背景渐变 + 圆角），不需要额外图片。

## 6. U 星球 IP 使用规范

| 规则 | 说明 |
|---|---|
| 最小尺寸 | 不小于 48rpx，小于这个尺寸行星环会糊成一团 |
| 安全边距 | 四周留 ≥ 图标宽度的 12%，不许被裁切 |
| 允许的变形 | 小幅旋转（≤15°）、缩放、加对话气泡 |
| 禁止 | 拉伸变形、改颜色、加投影滤镜（小程序 `filter` 会让整片变暗） |
| 主用途 | 底部导航中心键、空状态主图、加载动效、发布成功反馈 |
| 一个页面最多出现 | 2 次（超过就廉价了） |

## 7. 人物使用规范

| 规则 | 说明 |
|---|---|
| 三人组 | 只用在**首屏级**位置：登录页、首页 hero、分享卡 |
| 单人 | 用在**二级场景**：发现页分类头图、活动详情作者区、空状态 |
| 同屏人数 | 不超过 3 人，且必须是同一套画风 |
| 底部裁切 | `trio-back` 源图底边即裁切位，必须贴容器底对齐，不能居中留白 |
| 禁止 | 给人物加彩色描边框、圆形裁切头像（会破坏站位构图） |

## 8. 卡片语言（去 AI 味的核心）

通用商城/社区模板的卡片都是「纯白圆角 + 灰阴影 + 左图右文」。UNIDA 用四种卡片轮换，避免所有页面长一样：

| 卡片 | 形态 | 用在哪 |
|---|---|---|
| **A · 玻璃信息卡** | 半透明渐变 + 白边 + 内高光 | 分类面板、数据卡 |
| **B · 插画出血卡** | 插画顶到卡片上边缘，文字压在插画下沿 | 活动卡、组局卡 |
| **C · 标签流卡** | 无边框，靠彩色 chip 撑结构 | 兴趣、筛选、话题 |
| **D · 数据块** | 大数字 + 小标签，无卡片框，靠间距分隔 | 个人页数据、统计 |

一个页面里最多出现 2 种。

## 10. 技术栈说明（必须明确）

你的《总指令》里写的是「原生 WXML / WXSS / JS」，但当前工程是 **uni-app（Vue 3）+ uniCloud**，两者不兼容：

| | 原生小程序 | 当前 uni-app |
|---|---|---|
| 模板 | `.wxml` | `.vue` 里的 `<template>` |
| 样式 | `.wxss` | `.vue` 里的 `<style lang="scss">` |
| 逻辑 | `.js` + `Page({})` | `<script setup>` + Vue 3 组合式 API |
| 跳转 | `wx.navigateTo` | `uni.navigateTo` |
| 编译 | 微信开发者工具直接打开 | HBuilderX 编译到 `unpackage/dist/dev/mp-weixin/` |

**我的处理方式**：保持 uni-app（换回原生等于把已有的 29 个页面、登录页 V7、图标资产、tabbar 组件全部推倒重写）。

你给的 WXML/WXSS 代码我会**逐行翻译**成等价的 Vue/SCSS —— 结构、类名、样式值全部保留，只换语法外壳。视觉效果完全一致，只是能在这个工程里跑起来。

如果你确实想改用原生小程序，现在说还来得及；一旦第二阶段的页面做完再切，成本会翻几倍。
